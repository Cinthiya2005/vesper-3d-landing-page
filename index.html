Three steps, and most of them are invisible.

Vesper works in the gap between the first word and the last. Here is what happens in that gap.

1

It listens as you type

After a few words, Vesper narrows down what you are after: a metric, a policy, an action. Nothing is sent until it has a guess worth acting on.

2

It commits when it is sure

Once confidence passes the threshold you set, it starts pulling sources and drafting. Below the threshold, it waits.

3

It answers in place

The draft is on screen by the time you press enter. If you keep typing and the intent changes, the draft is dropped and Vesper starts over.

Drops into your stack

Attach it to any input. You choose the threshold.

import { Vesper } from "@vesper/js";

const v = new Vesper({ key: "vsp_live_..." });

v.attach("#search", {
  threshold: 0.85,
  onReady: (answer) => render(answer),
});

Private by default

Predictions run on the sources you connect and nothing else.

  • Runs in the region you choose.
  • Your data never trains shared models.
  • Every answer links back to its sources.

Questions people ask first

What if it guesses wrong?

It only shows an answer when confidence passes the threshold you set. If you keep typing and the intent changes, the draft is discarded and Vesper starts over.

Can I turn prediction off?

Yes. Set the threshold to 1 and Vesper waits for enter before it answers.

Which data can it read?

Only the sources you connect, and only with the permissions of the person asking.

What will it cost?
